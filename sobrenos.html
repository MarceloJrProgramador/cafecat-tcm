Sobre o Cafecat

Um projeto de cafeteria temática desenvolvido para o trabalho de conclusão do curso técnico.

Nossa proposta

Criar uma experiência digital que una café e o universo dos gatos, com identidade própria e navegação simples.

Nossa identidade

Cores acolhedoras, imagens temáticas e uma linguagem próxima para apresentar a marca Cafecat.

Nosso desenvolvimento

HTML5 estrutura as páginas, CSS organiza a apresentação e JavaScript adiciona as interações.
